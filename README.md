# Excel-Project
Project Overview

This project analyzes employee data using Microsoft Excel. The dashboard provides an interactive view of workforce size, salary distribution, department composition, age groups, manager status, and employee work experience. The data was cleaned and transformed before analysis to make it suitable for calculations, visualization, and dashboard reporting.

KPI Cards

Total Salary: Displays the total salary value across all employees. The dashboard shows ₹41,154,039.

Slicers / Filters

* Department – filters employees by Finance, HR, IT, Marketing, and Sales.
* Age Group – filters employees by Under 30, 30–50, and 50+ age categories.
* Is_Manager – filters employees into Manager and Not Manager groups.
* Salary Group – filters employees into Below 1 Lakh, 1–2 Lakhs, and 2 Lakhs+ categories.

Charts

Employees Salary Range: Shows the distribution of employees across salary groups.

Dashboard Interaction

The dashboard uses slicers to allow users to filter the workforce analysis interactively. Selecting a department, age group, manager status, or salary group updates the dashboard visuals, making it easier to examine specific employee segments and compare workforce characteristics.

Data Cleaning / Changelog

Index Number: Changed the index from 0-based values to a sequential numbering format for easier understanding.

Age: Converted the data type to number so age can be used correctly in calculations and analysis.

Join Date: Converted the data type into a short-date format to enable date/year analysis.

Experience: Converted the data type to number to enable calculations and analysis.

Salary: Converted the data type to currency for easier reading.

Age Group: Added age categories to simplify age-group analysis.

Salary Group: Added salary categories to simplify salary-range analysis.

Is_Manager: Converted True/False values into Manager/Not Manager categories for easier understanding.

Key Findings

* The dashboard contains 243 employees with a total salary value of ₹41,154,039.
* Finance represents the largest department share shown in the dashboard.
* The workforce is distributed across Finance, HR, IT, Marketing, and Sales.
* Employees are grouped into Under 30, 30–50, and 50+ age categories for easier age analysis.
* Salary is grouped into Below 1 Lakh, 1–2 Lakhs, and 2 Lakhs+ categories.
* Manager status is separated into Manager and Not Manager for workforce-structure analysis.
* Average work experience differs across departments, allowing department-level experience comparisons.
